# TaskFlow - Responsive Landing Page

A responsive landing page built as part of the O2H Mock Front-End Developer Assessment. The project converts a Figma design into a modern, responsive, and user-friendly website using HTML, CSS, and JavaScript.

## Features

- Responsive Navigation Bar
- Hero Section
- Features Section
- Pricing Cards
- Contact Form with Validation
- Mobile Hamburger Menu
- Dark Mode Toggle
- Responsive Design for Mobile, Tablet, and Desktop
- Semantic HTML & Accessibility
- Optimized Performance

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
